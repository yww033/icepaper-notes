摘要

Abstract

全文的「微型論證」：三個子議題（特徵生成、偏移導向的特徵選擇、樣本權重）在此一次排開。

¶1Abstract · 第一段作者中文摘要＋英文摘要

隨著計算機技術的發展，機器學習模型的應用逐漸演變成業界十分注重的議題之一。為了能使模型更能符合應用的目的，機器學習的建模需要盡可能地提高其預測的精確度，且同時要能夠泛化至不同的資料集。……在此之中，特徵工程是連結機器學習模型以及領域知識的一大橋梁，往往是影響模型能力的決定性因子，故在這篇論文中，我們會進一步探討各種特徵工程的議題，並且從嘗試這些議題中提升模型的表現。

作者英文摘要（對應段落）Today, applying machine learning techniques to solve the company’s problem is one of the biggest application issues in machine learning, feature engineering becoming the connection between the machine learning application and domain knowledge. Therefore, we will discuss some feature engineering issues and try to improve the model’s performance in this paper.
功能界定主題・引出問題
邏輯角色
全文起點，把「特徵工程」立為貫穿三個案例的主軸，後面每個實驗都回扣「特徵怎麼表示、怎麼篩選」。
技巧／漏洞
從「特徵工程很重要」直接用「故」跳到研究目的，中間沒有指出既有研究的缺口（英文摘要的「Therefore」也是同樣的跳躍）。「提升模型的表現」也沒說用什麼指標衡量（後文才知道是 F1）。
¶2Abstract · 第二段作者中文摘要＋英文摘要

在處理不同的應用情景時，會需要考慮多個面向：特徵的表示方式、特徵對目標任務的影響力以及資料不平衡問題的處理。適當的特徵表示方式可以增加該特徵對於目標任務的相關性，同時提升模型的效能。雖然如此，我們卻很難完整地找出所有可能的特徵表示方法因此，在這篇論文中，我們將運用特徵自動生成的方法，利用資料表格之間的關聯性，再經由函數的轉換，建構出多個不同的特徵來增加模型的複雜度，讓模型能從資料中更好地從有限的資料中學習到有用的訊息。

作者英文摘要（對應段落）While constructing a machine learning model, researchers must find the appropriate representative way of the features that can improve the influence of the attribute on the objectives. However, it is unlikely that researchers will find all the features in properly representative ways; thus, we introduce an automatic feature generation method to make feature engineering more complete.
功能提出子論點一（DFS）
邏輯角色
「人工有極限 → 自動生成補足」，是三條主線中的第一條。它預先替後文的「underfitting（欠擬合）診斷 → 用 DFS 補資訊」鋪路。
技巧／漏洞
先承認人工方法的極限，再提出解方，是標準的「缺口 → 填補」句式。「增加模型的複雜度」暗示特徵越多越好，跟第三段「刪除有害特徵」有張力。作者到結論才用「先補資訊、再去偏移」把兩者調和起來。
¶3Abstract · 第三段作者中文摘要＋英文摘要

另一方面，由過往的研究可以得知，並非所有特徵對於模型的泛化能力皆有所幫助，甚至可能會誤導模型的訓練過程，其中更有部分特徵會使模型在訓練集上可以很好地捕捉到某些態樣，然而在測試集上卻不存在這種特徵與目標間的關係性……因此我們考慮運用 Kolmogorov-Smirnov test，透過檢定測試集和訓練集特徵的分布差異，用以剔除掉在訓練集和測試集的分佈有所差異之特徵，作為機器學習的特徵選擇方法，以此方法便能避開資料集的問題，提升模型在預測中的泛化能力。其中，為了能夠再更進一步地觀察 Kolmogorov-Smirnov test 的效果，我們針對訓練集和測試集的所有特徵資料（不包含預測目標 label）進行 Discriminative Learning 方式檢驗資料集偏移問題，用以觀察訓練集和測試集的分佈是否相同。

作者英文摘要（對應段落）On the other hand, feature selection is an important process for selecting informative features. When analyzing a dataset, as not all features are necessary, researchers must determine which attributes are most relevant to the response variable. Here, we consider that dataset shift may deteriorate the performance of the machine learning model; in this paper, we suggest taking into account the difference of the pattern between training and testing, which the selection of features can be proxied by examining the similarity of their probability distributions with the Kolmogorov-Smirnov test. Since features with different patterns between training and testing may cause a dataset shift, removing these noisy features could significantly improve the performance of the model. To see the effect of features dropped by the Kolmogorov-Smirnov test, we will use discriminative learning to check the difference in the pattern between training and testing.
功能核心論點（全文主命題）
邏輯角色
本文最原創的主張：把「分佈穩定性」當成特徵選擇的準則，而不只看特徵與目標的相關性。KS 是處方，判別式學習是驗證工具，兩者構成「介入＋檢驗」的閉環。
技巧／漏洞
用獨立的檢驗工具（判別式學習）驗證介入的效果，不只看最終 F1，設計上很周全。中文摘要把問題寫成「特徵與目標間的關係在測試集不存在」，這其實是概念偏移（concept shift，P(y|x) 改變）；但 KS 只比較特徵本身的邊際分佈 P(x)，問題定義與工具並不對應。英文摘要寫「could significantly improve」，在保險資料上其實沒有成立（見 ¶37），屬過度承諾。
¶4Abstract · 第四段作者中文摘要＋英文摘要

此外，在我們的資料集中存在著資料不平衡的問題，處理此一問題的作法可以採用重複抽樣的方法對資料集進行調整……但從另一個角度思考，重複抽樣方法就如同於賦予各個資料不同的損失函數權重，將資料量大的類別賦予較小的權重，同時資料量小的類別賦予較大的權重，進一步影響模型的參數調整。……藉由改變權重設定來做 cost-sensitive learning，希望透過更改權重的方式讓模型的訓練能夠找到最適解，並因此提高模型的準確度。

作者英文摘要（對應段落）Last but not least, as the imbalanced dataset problem will degrade the classification performance, the resampling method, which replicates the samples of minority classes, is an important preprocessing skill for researchers to solve this problem. However, from another concept, we can see the resample as modifying the learning weight of the data during the learning process. In this paper, we introduce weighted cross entropy and cost-sensitive learning to modify sample weights, which can also be a solution to the imbalanced dataset problem.
功能方法論說明・子論點三
邏輯角色
第三條主線（樣本權重）。跟前兩條相比較為獨立，主要為後面驗證並反駁 Khan et al.（2017）做準備。
技巧／漏洞
把「重抽樣」重新詮釋為「損失權重」，是漂亮的概念轉換，讓兩種方法可以放在同一尺度上比較。摘要完全沒交代三條主線的實證結果，讀者看不到結論，只看到研究計畫。

緒論

Introduction

界定兩大問題（資料集偏移、特徵表示不完整），並交代三個案例、方法藍圖與結果預告。

¶5緒論 · 第一段作者中文原文・節錄

機器學習的模型在訓練時，若特徵在訓練集與測試集分佈具有顯著差異時，則會導致模型在訓練集學習到的結果，在測試集未能有良好的表現能力，這正是所謂的資料集偏移問題。此外，在建模過程中所使用的特徵裡，可能存在能夠改善模型表現但仍未被發現且應用的特徵表示方法，這些方法在我們人工製做的特徵工程上可能會難以被捕捉到，但若使用自動特徵生成方法則可以藉由特徵之間的相關資訊來進行特徵表示方法的擴展，便能夠解決此一問題。因此，在我們這篇論文裡，會研究三個不同方向的研究案例，分別是保單成交預測、金融帳戶洗錢偵測以及配對交易策略預測等財金領域上的機器學習應用和特徵工程議題。

功能定義核心概念・設定場域
邏輯角色
給出「資料集偏移」的操作型定義（特徵分佈不同），並宣告用三個異質案例檢驗同一套方法，是在為「外部效度」鋪路。
技巧／漏洞
這裡把資料集偏移等同於「特徵分佈不同」（covariate shift），但沒區分 prior shift 和 concept shift。後面的法規事件其實更像 P(y|x) 的改變，而 KS 原理上處理不了這種偏移。而且這個定義和中文摘要（¶3：特徵與目標的關係改變）並不一致。
¶6緒論 · 第二段作者中文原文・節錄

在本次實驗裡，我們在資料集偏移問題的研究，是在各個研究案例下做完特徵工程後，使用 Kolmogorov-Smirnov Test 特徵選擇移除掉訓練集和測試集分佈差異顯著的特徵，以此處理資料集偏移問題，之後再比較 Kolmogorov-Smirnov Test 特徵選擇前後的模型表現能力差異。最終以 Discriminative Learning 來分析及檢驗資料集偏移的狀況。……將訓練集和測試集中各抽樣 3/4 的資料集，並標記各個樣本資料是來自訓練集或是測試集部分，並以此資料集建構一個分類模型來判斷該筆資料是訓練集的資料抑或是測試集的資料。之後再運用訓練集和測試集中剩餘的 1/4 的資料集進行驗證，若模型能較清楚地分出訓練集的資料或是測試集的資料，則表示有資料集偏移的問題……在特徵自動生成架構中，我們則是參照 James et al.(2015) 的 Deep Features Synthesis 方法，其概念是在資料有多個表格時，會透過資料表格之間的關聯性進行特徵合成

功能方法論藍圖
邏輯角色
交代「處方（KS）＋療效檢驗（判別式學習）＋增補（DFS）」三件工具，對應摘要的兩個子論點。
技巧／漏洞
判別式學習是對抗式驗證（adversarial validation）的學術版本，用模型能力直接量化偏移，比逐一看 p 值更有整體性。判別分類器的 F1 會受訓練集與測試集樣本數比例影響，跨實驗比較 F1 時需要校正（見 ¶48）。另外，這裡把 DFS 引為「James et al.(2015)」，參考文獻與 ¶40 卻寫 Kanter & Veeramachaneni (2015)，引用前後不一致。
¶7緒論 · 第三段作者中文原文・節錄

在我們特徵工程的實驗部分，由於已成交保單以及警示帳戶的資料量較少，故資料集有不平衡的問題。所以在保單資料上，我們會嘗試採用 Over-sampling 的方式解決資料不平衡的問題，同時考慮 weighted cross entropy 亦可以處理不平衡資料集問題……另外參考 Khan et al.(2015) 的論文提出的 CNN 下 Proposed cost-sensitive learning 方法，將該文獻所提出的動態更新樣本權重之想法應用至我們的機器學習模型中。……此外，對於模型的初次實驗，我們會先針對類別變數進行 One hot encoding，接著再嘗試對這個資料集中具有順序性的類別特徵運用 One hot encoding、label encoding、target encoding，並分析與比較不同編碼下對模型表現的影響。……故我們嘗試運用 Deep Feature Synthesis 自動特徵生成的方式，產生多個特徵，增加模型的學習複雜度……我們採取了 AutoEncoder 方式進行資料降維的實驗

功能實驗清單
邏輯角色
列出保險案例的全部實驗分支。可以看出保險資料是「主實驗場」，另外兩個案例主要用來佐證。
技巧／漏洞
實驗分支很多（不平衡處理 3 種 × 編碼 3 種 × 降維 × DFS × KS），但每個分支都只做單次切分、單次訓練，沒有重複實驗或信賴區間，「顯著」的說法缺少統計支撐。Khan et al. 在這裡寫成 2015 年，其他地方都是 2017 年。
¶8緒論 · 第四段作者中文原文・節錄

經過我們的實驗發現，在金融帳戶資料上，透過 Kolmogorov-Smirnov test 做完特徵選擇後，模型的表現著實有顯著地提升，而在配對交易資料上，我們可以發現訓練集和測試集的分佈相同的特徵，對於尋找最佳交易模式可以有更好的報酬。而在保險的資料上，我們卻得到做完 Kolmogorov-Smirnov test 的特徵選擇後模型的表現並未有明顯改進的結果，然而再由 Discriminative Learning 檢測並發現到其中的原因可能是源於測試集的時間上，有 2020 年 7 月金管會提出的健全保險商品結構規範出現促使資料分佈有所改變，使得儲蓄險保單的銷售內容受到一定程度上的限制。

功能預告結果・預先讓步
邏輯角色
先承認反例（保險資料沒有改善），再立刻給出解釋（法規事件），把潛在的反駁轉成「論點適用條件」的補充。
技巧／漏洞
在緒論就主動處理不利結果，可信度比事後補救高。但這個解釋是看到結果之後才提出的（post-hoc），並非事前假設；而且法規改變的是購買行為本身，用剔除特徵來應對，本質上可能並不對症。

Literature Review

前三篇對應三個案例的「基準」，後四篇對應四件方法工具。整章以「引用＋借用」為主，批判性對話較少。

¶9文獻 · Wang (2020)作者中文原文・節錄

在 Wang (2020)，作者主要討論在汽車保險上的特徵建構，並且建立機器學習模型預測保險人是否會續保。……由表一可以看出模型在測試集的 F1-Score 約為 0.34。另外，作者列出了特徵重要性後發現到，對於汽車保險是否續約，汽車價格、車齡、汽車類型、汽車使用目的等，會是較為重要的特徵。然而在我們這次的研究裡，我們的資料集主要是人身保險部份，因此藉由這篇論文，我們引用其中的保險種類、被保人年齡、保費、保額、保險三標作為特徵初步的建構。

功能建立比較基準
邏輯角色
F1≈0.34 這個數字之後被當成「預期表現」的參照（例如 Learning Curve 以 0.4 判定 underfitting）。
技巧／漏洞
汽車續保與壽險新單成交是不同任務，正例比例也不同，F1 不能直接跨研究比較。拿它當基準，隱含一個未經檢驗的可比性假設。
¶10文獻 · 辛宥言 (2021)作者中文原文・節錄

在辛宥言(2021)，作者嘗試藉由帳戶、交易頻率、異常偵測方法和交易類型，建構新的特徵。之後比較他所建構的新特徵以及過往文獻所運用的特徵在模型表現上的效果，發現到他所建構的新特徵更能夠讓模型要較好的預測能力……而其中 WGAN 相關方法對模型的幫助較大。在作者的研究中，他亦發現到當他將過往文獻的特徵進行 Kolmogorov-Smirnov test，捨棄掉訓練集與測試集分佈不同的特徵，能讓模型有較佳的表現。綜上所述，在我們的研究中，我們會分別對這篇論文提出的特徵和過往文獻提出的特徵，進行特徵自動生成，嘗試進一步提升模型的預測能力。

邏輯角色

¶11文獻 · 郭瑋倫 (2021)作者中文原文・節錄

¶12文獻 · Bickel (2007); Nair et al. (2019)作者中文原文・節錄

在 Bickel (2007) 和 Nair. et al. (2019) 論文中，作者提出能夠檢驗訓練及和測試集分佈是否有差異的方法，此方法是先將所有資料切分成訓練集（寫作 tr1）和測試集（寫作 ts1）並且在 tr1 和 ts1 裡各隨機抽樣 3/4 的樣本點統合作為 discriminative learning 的訓練集（寫作 tr2），而 tr1 和 ts1 裡各剩下 1/4 的樣本點統合作為 discriminative learning 的測試集（寫作 ts2）。……如果模型能很好地在 ts2 上分類出資料點是來自 tr1 或 ts1，則表示 tr1 和 ts1 的特徵分佈差異甚大，使模型能從中區分。因此表示這些特徵會有 covariate shift 的問題。故我們所採取的對 covariate shift 問題檢測方法，運用機器學習判斷 ts2 的資料點來自 tr1 或 tr2，所得到的 F1-Score 進行診斷。

功能檢驗工具定義
邏輯角色
這是全文的「量尺」：之後所有「偏移減緩」的主張，都以判別 F1 下降為證據。
技巧／漏洞

¶13文獻 · Pettitt & Stephens (1977)作者中文原文・節錄

另外我們資料的特徵很多是類別資料，而 Kolmogorov-Smirnov test 的應用是在連續變數的分佈差異檢定。因此為了能證實 Kolmogorov-Smirnov test 在類別資料上的適用性，我們參考了 Pettitt and Stephens (1977) 的方法，論文中給出了證明了類別資料可以視作是數個相異的直方圖的分箱（the equal cell case），並且可由直方圖分箱計算其累積機率分佈，如此便能將類別變數視為如同連續變數的計算方式。故我們亦能運用 Kolmogorov-Smirnov test 對類別特徵做特徵選擇。

功能預先反駁方法上的異議
邏輯角色
先預想審查者會問「KS 能用在類別變數嗎？」，再引權威文獻擋下，替後續大量 one-hot 特徵的 KS 篩選取得合法性。
技巧／漏洞
預先處理異議是好習慣。但 Pettitt & Stephens 的重點其實是：離散資料下若沿用連續情況的臨界值，檢定會偏保守，必須改用專門的臨界值。本文直接用標準 p 值處理 0/1 的 one-hot 特徵，等於引用了文獻卻沒照它的修正做。

¶21方法 · 業務員特徵與「年資外經驗」作者中文原文・節錄

業務員年齡 = 業務員年資 + 20 + ϵ
其中，我們的資料集的時間段（2018 年 9 月至 2020 年 9 月）中的法規規定業務員最低年齡為 20 歲。從上式我們可以推算出在年資外的工作經驗為：
業務員年資外經驗 = ϵ = 業務員年齡 − 業務員年資 − 20

Conclusion

¶52結論 · 保險特徵工程作者中文原文・節錄

我們在保險資料集中，由特徵工程方法，發現到業務員資訊對於保單成交預測是為有幫助的資訊……另外，從我們的實驗中亦可以發現到，客戶財富等級和忠誠度等級的順序性對於保單預測結果影響不大。在保單成交預測的實驗上，我們得出使用 AutoEncoder 對特徵進行降維，對模型的表現反而會造成下降的現象……在我們的實驗中，Oversampling 或已成交保單樣本權重設定為 未成交保單數量／已成交保單數量 和未成交保單樣本權重設定為 1，方能使模型的 F1 Score 表現較佳。而使用梯度更新方法（如 Khan et al.(2017)【8】論文所提出的樣本權重矩陣迭代方法）動態調整不同樣本的權重，其模型表現反而變差許多。

¶53結論 · 資料集偏移作者中文原文・節錄

資料集偏移問題部分，我們透過保險資料集、金融帳戶資料集和配對交易資料集驗證出 dataset shift 問題可以透過 Kolmogorov-Smirnov test 進行特徵選擇，以捨棄訓練集和測試集分佈不同的特徵方式解決。……故我們推測應是當特徵提供的資訊足夠充分（即模型 underfitting 問題較輕時），將訓練集和測試集中，P 值較小的特徵捨去掉，著實可以使模型的表現更佳。然而我們亦發現到，若在測試集期間若有如法規變動等的事件發生，抑或是特徵會不停因時而變，則在訓練集和驗證集上做 Kolmogorov-Smirnov test 特徵選擇，嘗試要捨棄測試集跟訓練集分佈相異的特徵，可能會捨棄過多的特徵，或是錯誤地捨棄對模型預測有效的特徵，從而未能使模型的表現變好。

¶54結論 · DFS 與稀缺的金融資料作者中文原文・節錄

另外，基於金融資料是相當稀缺的，故當我們建模時可能較難以增加特徵的數量來加強機器學習模型的表現，進而出現 underfitting 問題。因此我們提出 Deep Feature Synthesis 將會是可以更完整地做特徵萃取的一個特徵自動生成的方法。藉由其透過表格間的關聯性來幫助模型產生特徵，進而解決 underfitting（抑或是 High Bias）的問題，提供模型更多的特徵表示方式，增加模型從特徵中可以取得的資訊。
